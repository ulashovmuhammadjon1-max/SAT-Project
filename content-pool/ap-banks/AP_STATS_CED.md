## READ THIS FIRST — the course was redesigned, and it changes the unit numbering

**AP Statistics has been revised for the 2026-27 school year "to align with current
introductory college statistics courses."** The framework that was in force from
Fall 2019 through 2025-26 had **nine** units. The framework now in force has **five**.

Any brief, blog post, review book or prior memory that refers to "Unit 3: Collecting
Data", "Unit 5: Sampling Distributions", "Unit 6: Inference for Categorical Data" or
"Unit 9: Inference for Quantitative Data: Slopes" is describing the **retired** 2019
CED. Do not use those numbers.

How the old content maps onto the new units:

| old 2019 unit | where that content lives now |
|---|---|
| 1 Exploring One-Variable Data | Unit 1, topics 1.1–1.9 |
| 2 Exploring Two-Variable Data | split: **categorical** pairs → Unit 2, topics 2.1–2.2; **quantitative** pairs (scatterplots, correlation, regression, residuals) → **Unit 5** |
| 3 Collecting Data | Unit 1, topics 1.10–1.13 |
| 4 Probability, Random Variables, and Probability Distributions | Unit 2, topics 2.3–2.11 |
| 5 Sampling Distributions | dispersed: 2.12 (CLT), 3.2, 3.9, 4.1 |
| 6 Inference for Categorical Data: Proportions | Unit 3 (now also absorbs the chi-square topics) |
| 7 Inference for Quantitative Data: Means | Unit 4 |
| 8 Inference for Categorical Data: Chi-Square | folded into Unit 3, topics 3.14–3.15 |
| 9 Inference for Quantitative Data: Slopes | **removed** — inference for slopes is no longer in the course |

Two further consequences worth recording: **inference for the slope of a regression
line is gone from the course entirely**, and **regression is now taught at the end
(Unit 5) rather than at the start**, as descriptive two-variable work rather than as
a lead-in to inference.

**Two things the 2019 CED taught are gone from Unit 2. Do not author topics for them.**

*The geometric distribution is not a topic in this framework.* The 2019 CED carried
it (old 4.12); the Fall 2026 unit at a glance lists only the binomial. It is still
worth one or two contrast items inside 2.10 — "is this a binomial setting?" turns on
a fixed number of trials, and the natural foil is waiting for a first success — but a
topic module for it would be inventing a topic the CED does not have.

*Combining random variables is not in the framework either.* The 2019 CED had a topic
on the mean and standard deviation of a sum or difference of independent random
variables (old 4.9–4.10). Topic 2.9 here is **only** 2.9.A (calculate the mean and
standard deviation of one discrete random variable) and 2.9.B (interpret them in
context) — there is no 2.9.C. A full-text search of the CED for "combin" finds only
the *pooled* proportion in Unit 3's two-sample tests, which is a different idea.

This matters because "the expected value and standard deviation of a linear
combination" is a standard item on every review list for the retired course, and it
was on the brief for this bank. It has no CED topic to attach to now, so no module
here carries it. If it is ever wanted, it belongs as enrichment, not as a topic.

## Scope note for the bank authored against this file

The brief for this bank asked for "Units 1 through 4 … roughly Exploring One-Variable
Data, Exploring Two-Variable Data, Collecting Data, and Probability/Random Variables/
Probability Distributions", and said to follow the research where it disagrees.

It disagrees. That content paraphrase is exactly Units 1–4 of the **retired** nine-unit
CED. Under the framework confirmed above the same content is **Unit 1 + Unit 2 + Unit 5**
— it does not include a single inference topic, whereas "Units 1 through 4" of the
current CED would be more than half inference (Units 3 and 4, 25 of the 55 topics).

The research was accepted and the work was re-divided against the confirmed
framework rather than the retired one. **The split now in force is:**

| agent | scope | topics |
|---|---|---|
| this bank | **Unit 1, Unit 2, Unit 3** | 13 + 12 + 15 = **40** |
| sibling | **Unit 4, Unit 5** | 10 + 5 = **15** |

So the descriptive/collecting/probability content of the original brief is covered
here, plus all of the proportion inference in Unit 3; regression (Unit 5), which is
the brief's "Exploring Two-Variable Data", moved to the sibling along with Unit 4.

The brief's list of most-missed ideas maps onto CED topics as follows. Note that
three of them — correlation, influential points, residual plots — land in **Unit 5**
and are therefore the sibling's to cover, not this bank's:

| idea | topic | whose |
|---|---|---|
| correlation is not causation | 5.2, and 1.13 for the design half | shared |
| r unaffected by linear rescaling | 5.2 | sibling |
| influential points vs outliers vs high leverage | 5.4, 5.5 | sibling |
| slope and intercept in context with units | 5.3 | sibling |
| residual plots and what a pattern means | 5.4 | sibling |
| parameter vs statistic | 1.2, 3.1 | this bank |
| random assignment (causation) vs random sampling (generalization) | 1.11, 1.13 | this bank |
| bias vs variability | 1.12, 3.1, 3.2 | this bank |
| mutually exclusive vs independent | 2.5, 2.7 | this bank |
| binomial vs geometric setting | 2.10 | this bank |
| expected value and SD of a linear combination | 2.9 | this bank |

## Exam format

The exam is **3 hours** long, in two equally weighted 90-minute sections.

| section | question type | count | weighting | timing |
|---|---|---|---|---|
| I | Multiple choice | 42 | 50% | 90 minutes |
| II | Free response (10 points each) | 4 | 50% | 90 minutes |

Section II, in the order the questions appear:

| question | focus | weighting |
|---|---|---|
| 1 | Multi-focus on Practices 1 and 2 | 12.5% |
| 2 | Multi-focus on Practices 3 and 4 | 12.5% |
| 3 | Inference (hypothesis test or confidence interval) | 12.5% |
| 4 | Multi-focus on Practices 2, 3, and 4 | 12.5% |

The multiple-choice section is "comprised of discrete and set-based questions" —
some questions share a common prompt.

**This is a change from the retired framework**, which ran 40 multiple-choice
questions and **six** free-response questions. It is now 42 and **four**.

### Calculator policy

"A graphing calculator with statistical capabilities is **expected** for both
sections of the exam" — expected, not merely permitted, and for *both* sections.
Formulas and tables (normal, t, chi-square) are provided for both sections in the
exam's appendix. Accessible technology with the same capabilities is available
through Services for Students with Disabilities.

The practical consequence for authoring: a question may require a normal or binomial
probability that only technology or the supplied table gives, and that is fair game.
It should not require a table lookup so coarse that the intended answer depends on
which table edition the student holds.

## Statistical practices and their MC weighting

| practice | MC weighting |
|---|---|
| 1 — Formulate Questions | 5–10% |
| 2 — Collect Data | 20–30% |
| 3 — Analyze Data | 25–35% |
| 4 — Interpret Results | 25–35% |

Skill codes referenced on the topic pages: 1.A; 2.A, 2.B; 3.A, 3.B, 3.C, 3.D;
4.A, 4.B, 4.C, 4.D.

Practice 2 at 20–30% is the highest-weighted single practice after analysis and
interpretation, which is the CED's own confirmation that **data-collection
reasoning — random sampling versus random assignment, bias, scope of inference —
is not a side topic.** It is roughly a quarter of the multiple-choice section.
